# Python Developer Internship Projects

A collection of Python projects developed as part of my Python Developer Internship at Auspify Technologies.

## About

This repository contains four Python projects demonstrating programming fundamentals, GUI development, web development, API integration, and database management.

## Projects

### 1. Password Generator
- Generates secure random passwords.
- Allows users to customize password length and character types.
- Built using Python, Flask, HTML and CSS.

### 2. To-Do List Web Application
- Add, complete and delete tasks.
- Track pending and completed tasks.
- Stores tasks using SQLite.
- Built using Python, Flask, HTML and CSS.

### 3. Calculator GUI
- Performs basic arithmetic operations.
- Includes a graphical user interface.
- Built using Python and Tkinter.

### 4. Weather App – Weatherly
- Search weather by city name.
- Displays temperature, weather conditions, humidity and wind speed.
- Fetches live weather data using OpenWeather API.
- Built using Python, Flask, Requests, HTML and CSS.

## Technologies Used

- Python
- Flask
- SQLite
- Tkinter
- HTML5
- CSS3
- REST API
- OpenWeather API
- Git and GitHub
