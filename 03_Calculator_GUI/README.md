# Calculator GUI

A desktop calculator application built using Python and Tkinter. It provides a simple graphical interface for performing basic mathematical calculations.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Parentheses support
- Clear button
- Backspace functionality
- User-friendly graphical interface
- Dark-themed design

## Technologies Used

- Python
- Tkinter

## Project Structure

```text
03_Calculator_GUI/
└── calculator.py
```

## How to Run

1. Open the project folder in VS Code.
2. Make sure Python is installed.
3. Run the following command:

   ```bash
   python calculator.py
   ```

4. The calculator window will open.
