# Secure Password Generator

A web-based password generator built using Python and Flask. It helps users create strong random passwords with customizable options.

## Features

- Generate random passwords.
- Customize password length.
- Choose uppercase letters, lowercase letters, numbers and special characters.
- Generate multiple passwords.
- Copy generated passwords to the clipboard.
- Simple and responsive user interface.

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Secrets module

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/14-Palak/python-developer-internship.git
```

2. Open the project directory:

```bash
cd python-developer-internship/01_Password_Generator
```

3. Install Flask:

```bash
python -m pip install flask
```

4. Run the application:

```bash
python app.py
```

5. Open your browser:

```text
http://127.0.0.1:5000
```
